# Bewerbungs-Tracker

Ein einfacher Bewerbungs-Tracker in Java.

## Funktionen

- Bewerbungen speichern
- Firmen verwalten
- Status verfolgen
- Daten lokal speichern

## Projektstruktur

src/main/java/com/tracker

- model → Datenklassen
- service → Geschäftslogik
- repository → Speicherung
- Main → Programmstart

## Technologien

- Java
- IntelliJ IDEA
- Gradle (oder Maven)

## Starten

Programm starten über:

Main.java
